# 第一章：暴雨来客

## 场景1：庄园门口
[脚本: add_affection(target="butler", amount=1)]

你站在黑石庄园的铸铁大门前，暴雨倾盆，马车夫的灯笼在风中摇曳。

**如果** affection.butler >= 3 **则**
  管家塞巴斯为你推开门，露出一丝难得的微笑：「您来得正是时候，夫人已等候多时。」
  [脚本: unlock_clue(clue="管家的微笑")]
**否则**
  管家塞巴斯只是礼貌地颔首，引你入内。
**结束**

## 场景2：宴会厅
你被引入宴会厅，烛光在镶金的天花板上投下摇曳的光影。厅内宾客低声交谈，神情却有些不安。

**如果** weather == "stormy" **则**
  [脚本: unlock_clue(clue="暴雨中的脚印")]
**结束**
